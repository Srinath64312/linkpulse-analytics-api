DEVELOPER PLAYGROUND

RESTful API Reference & Live Interactive Runner

Directly test LinkPulse endpoints from your browser or copy production cURL commands.

GET /health System health check, uptime, and database telemetry 
curl -X GET http://localhost:5000/health
POST /api/auth/register Register new user account with Bcrypt hash 
curl -X POST http://localhost:5000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"Srinath","email":"srinath@example.com","password":"StrongPassword123!"}'
POST /api/urls/shorten Create short URL (optional custom alias & expiration) 
curl -X POST http://localhost:5000/api/urls/shorten \
  -H "Content-Type: application/json" \
  -d '{"originalUrl":"https://github.com/Srinath64312","customAlias":"srinath-hub","title":"Portfolio"}'
GET /api/urls/:code/analytics Aggregate click counts, referrers, and device breakdown 
curl -X GET http://localhost:5000/api/urls/campus-market/analytics
GET /:code HTTP 302 Redirect to destination with async telemetry 
curl -I http://localhost:5000/campus-market
